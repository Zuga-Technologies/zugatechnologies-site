# Zuga Technologies — Corporate Site

The corporate and investor landing page for **Zuga Technologies**, builder of
autonomous AI agents, agent-security infrastructure, and MCP tooling. This is the
company site — distinct from the **zugabot.ai** product.

Built with [Astro](https://astro.build).

## Develop

```sh
npm install
npm run dev      # local dev server at localhost:4321
npm run build    # production build to ./dist/
npm run preview  # preview the production build
```

## Structure

- `src/pages/` — routes (file-based)
- `src/components/` — UI components
- `public/` — static assets
